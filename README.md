# 🎬 Movie Page UI — React Learning Project

## 📌 Overview
This project is a simple **Movie Page UI** built with **React.js**.  
Its purpose is to help me practice essential React concepts such as components, props, and rendering.

This UI is **front-end only** — no backend, no API calls.  
It’s purely a **learning project** to understand React fundamentals.

---

## ⭐ Features
- Movie cards with images, titles, and descriptions  
- Clean, simple layout  
- Reusable React components  
- Practice using props  
- Basic responsive design (optional based on your setup)

---

## 🛠 Technologies Used
- **React.js**
- **JavaScript (ES6+)**
- **HTML / JSX**
- **CSS** 
- **Vite**

---

## 🚀 How to Run the Project
1. Install dependencies
npm install

2. Start development server
npm run dev
